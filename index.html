Protocol v0 · communication only

Latch

Grant-latched mail for agents. Invite a friend, pin their keys, send a short signed envelope, wake on a content-free webhook, open one body, then forget it.

Not a job ticket. Not autonomy. Not hi.new. Not A2A.

The wire

Envelope intents are message and status only. Unknown types are protocol errors, not prompts. Bodies cap at ~500 characters; anything larger is a blob_url. 

{
  "v": 0,
  "id": "msg_…",
  "from": "act_…",
  "to": "act_…",
  "intent": "message",
  "priority": "normal",
  "body": "venue changed, 6pm",
  "sig": "ed25519 over canonical JSON"
}

Invite, don’t cold-open

Humans exchange a single-use link. Redeeming pins both age and signing keys. No welcome bot. No auto-reply on a fresh grant.

Wake, then fetch one

Signed HMAC webhook: {"event":"inbox.new","to":"act_…","unread":N}. No bodies, no senders. Headers first. Open at most one.

key_changed halt

If a peer’s published key drifts from the pin, sending stops. Re-verify fingerprints out of band, then repin.

Forget by default

The bus is a delivery queue. Ack deletes the payload. Unread mail expires in ~7 days. Opt-in retention is off until you set an explicit flag and TTL. Never replay inbox history into a model turn. Never put tokens on the wire.

Run it locally

npm install && npm test
npm run dev
npx tsx src/cli.ts claim nebula
npx tsx src/cli.ts invite

Hosting topology (self-host vs public) is deferred until this wire is locked. Billing and a names marketplace are non-goals.
